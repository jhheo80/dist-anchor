# 동원과학기술대학교 경남 ANCHOR 사업 홍보 사이트

‘지역과 함께, 미래를 혁신하다’ — 동원과학기술대학교 동원앵커사업단의 모바일 반응형 홍보 웹사이트입니다.
2026년도 경남앵커사업 리플렛 내용을 바탕으로 제작되었습니다.

## 구성

| 파일 | 내용 |

## 내용 수정 방법

HTML 파일을 직접 고쳐도 되지만, 공통 헤더·푸터·메뉴가 모든 페이지에 반복되므로
`build.py` 안의 데이터를 고친 뒤 다시 생성하는 방식을 권장합니다.

```bash
python3 build.py    # (Windows) python build.py
```

`build.py` 상단의 `SITE`, `ADDR`, `TEL`, `PROJECTS`, `TASKS`, `DEPTS`, `ROADMAP`,
`COUNCIL` 값을 수정하면 모든 페이지에 반영됩니다.

## GitHub Pages 배포

이 저장소는 정적 사이트이므로 별도 빌드 없이 그대로 배포됩니다.

1. 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main / (root)**
3. 저장 후 1~2분 뒤 발급된 주소로 접속

## 디자인 기준

- 브랜드 그린 계열(리플렛 색상 기반) + 프로젝트별 구분색(그린·틸·오렌지·플럼)
- 본문 16px 이상, 명도대비 WCAG 2.1 AA(4.5:1) 충족
- 터치 영역 최소 44×44px, 키보드 포커스 표시, `prefers-reduced-motion` 대응
- 모바일 우선(375px) → 태블릿(768px) → 데스크톱(1024px 이상)
